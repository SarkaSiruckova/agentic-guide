This is a personal field guide to agentic AI. It explains the ideas in plain language first, then introduces the proper terms, so the vocabulary builds up naturally.

It grows over time. Each time a new concept comes up, it gets its own page here.

## What's inside

**[Start here](/start-here/how-to-use/)** explains how the guide works, suggests a reading order, and holds the glossary.

**[1. Concepts](/concepts/)** covers the ideas: how models work, what makes something an agent, how agents reach your data, and what it all costs.

**[2. The map](/map/)** shows how every piece of AI infrastructure fits together, from cloud providers down to the chat window.

**[3. Model landscape](/models/)** is a snapshot of the main model providers and what each is good for.

**[4. Setup and practice](/setup/)** is hands-on: GitHub, Vercel, Claude Code, Cursor, connecting tools, and not wasting tokens.

**[5. Comms channels](/channels/)** covers talking to agents through Teams, WhatsApp, Slack and others.

Use the search bar at the top, or **[browse by tag](/tags/)**.
