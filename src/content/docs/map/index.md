This section starts from first principles: what kinds of infrastructure exist, what each one does, and how they connect to make an agent work.

The centrepiece will be one large, interactive diagram with example providers at every point, followed by a page per layer:

- Compute and cloud
- Model access platforms
- Open-model hosting
- Specialised models
- App hosting
- Databases and storage
- Connectors and integrations
- Agent frameworks
- Observability and evals
- Auth and secrets
- Interfaces

It ends with a worked example that traces one question through every layer.
